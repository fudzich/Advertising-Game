Университетский проект  на тему: "Создание квиз игры для бренда".

Игра создавалась для тоговой сети "Пятерочка". Визуальное оформление игры (шрифты, цвета, наименования и т.д.) сделаны в соответсвии с "Руководством по использованию фирменного стиля торговой сети «Пятёрочка»" (версии 1.2) и их официальным сайтом.

Руководство по использованию фирменного стиля торговой сети «Пятёрочка»: [five_compressed.pdf](https://github.com/user-attachments/files/24025906/five_compressed.pdf)
