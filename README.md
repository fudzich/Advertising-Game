Игра сделанная для студенческого хакатона. Проект на тему: “Создание игры для приложения/сайта бренда”. Жанр игры: Аркада. Разработана за 24 часа.

Достижения:
  - Визуальное оформление (шрифты, цвета и т.д.) сделано в полном соответствии с официальным руководство по использованию фирменного стиля торговой сети “Пятёрочка”.
  - Адаптировал управление для игры только мышкой ил одним пальцем
  - Добавил вариативность наград для стимулирования реиграбельности
  - Ограничил игровые сессии 1 минутой для большего удержания внимания игроков
