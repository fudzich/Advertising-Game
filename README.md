ENG:

A game made for a student hackathon. Project on the topic: “Creating a game for a brand application/website.” Game genre: Arcade. Developed in 24 hours.
The game was made for Russian chain of convenience stores "Pyaterochka".

Achievements: 
- Visual design (fonts, colors, etc.) is made in full accordance with the official guidelines for using the corporate style of the Pyaterochka retail chain. 
- Adapted controls for playing with only a mouse or one finger 
- Added reward variability to encourage replayability 
- Limited gaming sessions to 1 minute to keep players' attention longer

RU:

Игра сделанная для студенческого хакатона. Проект на тему: “Создание игры для приложения/сайта бренда”. Жанр игры: Аркада. Разработана за 24 часа.
Выбранный бренд:"Пятёрочка"

Достижения:
  - Визуальное оформление (шрифты, цвета и т.д.) сделано в полном соответствии с официальным руководство по использованию фирменного стиля торговой сети “Пятёрочка”.
  - Адаптировал управление для игры только мышкой ил одним пальцем
  - Добавил вариативность наград для стимулирования реиграбельности
  - Ограничил игровые сессии 1 минутой для большего удержания внимания игроков
